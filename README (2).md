A program that draws one invented passport spread for the Republic of Kalvera, a country that isn't there — data page with portrait and machine-readable zone, visas and arrival/departure stamps from its neighbours, and one endorsement that reveals what kind of place Kalvera is. Pure Python 3.13 stdlib: the vector typeface, the portrait, the stamps and the PNG encoder are all drawn from scratch in `main.py`, no dependencies, no network. Two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
